# 极坐标显示与抗崩溃 checkpoint

源码标签：`checkpoint/polar-stability-cycle1-2026a`，基于已安装的 `e8a71ff`。版本仍为 2026a / 1.8.0。本次未重新安装。

普通转极坐标和参数转极坐标的实际命令是 `cart2polar`、`param2polar`。优先返回 `r=…`：

| 输入曲线 | 输出 |
| --- | --- |
| `x^2+y^2=4` | `r=2` |
| `x^2/4+y^2/9=1` | `r=6/sqrt(9*cos(theta)^2+4*sin(theta)^2)` |
| `(x^2+y^2)^2=4*(x^2-y^2)` | `r=2*sqrt(cos(2*theta))` |
| `x^2+y^2=4*x` | `r=4*cos(theta)` |

偏心正定二次曲线保留两个半径根；无实点的圆返回空列表。根式按实数定义域使用，分母必须非零。中心二次曲线采用非负半径，借助角度平移保留完整笛卡尔点集；不保留同一点的所有负半径标签。过原点的直线、可能退化的未知参数因子以及不能安全除去二次系数的曲线继续保留隐式式子。

首批全新出题代理仅出题，交付后结束。12题首次7题完整通过；失败项为 I1、I2、D1、D3、R2。其中小栈积分和导数化简发生 SIGSEGV，大乘积化简发生分配失败。主代理完成以下修复：

- 有界稀疏多项式系数匹配识别三角对数的带权换元，不在输出中除以相位导数，保留驻点。
- Li2 原函数支持高斯有理常数斜率的复指数；实定积分捷径拒绝未证明安全的复路径。
- 单位圆 Li2 实部求导使用主辐角周期公式；虚部求导对多项式相位驻点使用惰性零分支，补上可去端点。
- 化简在三角乘积预计超过64项时保留原式，阻止高维多项式展开。预算和CAS堆均未提高。

修复后12题48项全部通过，包括实际代入 x=±1 的导数值0。60项极坐标显示/定义域检查、两批旧混合题96项、21项正式回归任务及7项补充任务通过。完整用户矩阵仍为34项精确结果和2项正确发散拒绝。通用积分测试器不具备该矩阵的参数设置/特殊函数验证能力，其不适用结果另存诊断，矩阵使用专用验证器验收。

SH4构建：ROM 2,062,004 / 2,065,152 B，余3,148 B；AC2 2,468,064 / 2,559,996 B，余91,932 B；静态RAM 424,620 B及配置CAS堆1,572,864 B不变。主机5次进程中位数：PC1-D3外层化简约226 ms→0.83 ms；该题的主机小栈崩溃也已消失。失败的旧积分和分配失败不能作为成功计算的加速比基线。

这些测试使用实际仓库计算模块及主机Giac依赖，64 KiB保护栈不是SH4/MMU模拟，尚不能保证所有实机TLB错误消除。本轮首测存在错题，因此下一步必须重新派发全新题目，不能立即进入最终性能代理验收。

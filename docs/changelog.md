# 当前变更

- 生产源码集中到 `src/`；构建输入、测试查找和工具共享同一套路径解析。
- 手写 C/C++ 统一格式；保留版权、生成文件及有效的控制台头文件链接。
- 极限模块的公共元素查找返回正确的首次匹配索引，避免调用处使用尾后索引。
- 文档只描述当前状态；测试报告使用 `docs/bench/` 固定文件名，工作中间结果写入 `.build/`。
- 测试保留有效数学题及边界验证，移除重复快照、一次性生成器、过时汇总器和主机库自测；共享当前源码的化简探针依赖。
- `make test` 按显式指定的入口执行，验证范围限于核心改动直接影响的必要行为。
- 提交要求 OpenPGP 签名；推送检查提交和标签的签名。安装包及本地缓存不跟踪。

构建和回归证据见 [verification.json](bench/verification.json)。当前新题仍有未求出与定义域问题，见 [tests-set.md](tests-set.md)。此变更未执行设备安装。

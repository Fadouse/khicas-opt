## 性能与实现

每题每版交替运行11个新主机进程，计解析与求值时间的中位数。这些是逐题主机数据，不能外推为CG50实机或所有计算的提速。

| 路径 | 修改前 | 修改后 | 加速比 |
| --- | ---: | ---: | ---: |
| MR2-D1，非线性实相位Li2导数再化简 | 12.891 ms | 0.462 ms | 27.92倍 |
| MR1-D1，线性实相位导数 | 1.938 ms | 0.471 ms | 4.11倍 |
| MR2-C1，旋转椭圆转换再化简 | 2.895 ms | 0.767 ms | 3.77倍 |
| 叶形线相关三角商化简 | 5.410 ms | 0.361 ms | 15.00倍 |

最后一行输入为 `simplify(3*sin(x)*cos(x)/(sin(x)^3+cos(x)^3))`。其他已测积分、导数及大多数转换约为原速。MR1-C2恢复短旋转形式后为1.00倍，避免配平方引入额外根式造成的退步。[全部25题逐次记录](benchmarks/performance-final-2026a.json)。

* **导数避免重复定号。** 已证明实相位的Clausen恒等式直接保留绝对值和对数节点，避免通过通用绝对值入口再次进行全局Sturm定号。普通求导及外层化简中的主机PARI警告消失；正负区间、驻点和数值代入经过核验。
* **圆锥选择较短的可逆变换。** 对已证明非零的枢轴采用 `U=X+B*Y/(2*A)`，二次型成为 `A*U^2+det*Y^2/(4*A)`。可逆映射保留完整圆周和双曲线两支。有理特征值间距优先保留短旋转式，未知枢轴保留原有特征向量路径。MR2-C1外层化简后的标签节点 **173→46**，显示预算仍为256。
* **复用局部符号证明。** 减少重复相反数、遍历和因式分解；未知符号仍尝试原有负形式证明。正、负、零和未知严格区分，不假定参数平方严格为正。
* **Li2系数改为静态只读表。** 12个系数、运算顺序和精度预算不变，避免每次调用初始化自动数组，数值核SH4单帧 **296→212 B**。
* **修复回归发现的叶形线化简崩溃。** 转极坐标后的高次三角分母曾在通用改写中膨胀，使完整转换链在64 KiB主机栈崩溃。短的这类商式现在只做有理归一化，并限制结果不增长。3、4、5、7次幂变体检查等价性及分母零点；40项完整转换链随后全部通过。

## 逐项剩余缺口

1. `eval(subst(diff(im(Li2(exp(i*x^2))),x),x=0))` 当前为`undef`，真实导数为0。现有实相位恒等式只保证正弦非零区间，尚未自动延拓这个复合端点；不计成功。
2. `eval(diff(im(Li2(exp(i*(x^2+pi/4)))),x))` 仍可能重新进入通用绝对值定号，在主机产生PARI警告。本轮加速覆盖直接求导和外层化简，并未覆盖所有后续求值路径。
3. 未知参数下，例如 `a*x^2+x*y-a*y^2=1`，保留a=0及正负a覆盖的旧回退可能超过256节点显示预算。旧输出保留检查不等于完整显示通过。
4. 主机使用仓库积分、实际 `yderive.cc`、归一化、FXCG化简及转换，其他依赖仍为主机Giac。64 KiB线程栈不是SH4/MMU模拟，不能保证实机TLB全部消除；尚需设备连续运算、峰值内存与耗时测量。
5. 资源余量如上，尚未达到所有物理容量上限，也不能由有限题库推出所有积分都能求闭式。安全保留未求解式不得计作成功。

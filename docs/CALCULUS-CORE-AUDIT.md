# 第十七轮计算核心审查

这份审查区分数学正确性、适用范围、表示大小和运行资源。通过有限题集不能证明所有表达式安全；新增算法必须有可检查的前提，证明不足时保留通用求解路径。主机受限栈不是 SH4/MMU 仿真。

## 1. 对数端点：先合并局部奇异项，再判断极限

原先 `integrate(ln(x)/(1+x)^2,x,0,1)` 已能找到原函数，但在端点进入通用极限、定号和内部解析器，64 KiB 主机栈崩溃。问题发生在求原函数后的端点求值，不是缺少这道题的积分表。

新路径把有限个实仿射对数写成同一个单侧局部对数加有限常数：`ln|a(x-p)|=ln|x-p|+ln|a|`。普通 `ln(a*x+b)` 另外检查实际逼近方向，不能借用绝对值分支。求值可能先把 `abs(a*x)` 写成 `abs(a)*abs(x)`，两种写法使用同一证明。

收集后得到 `R(x)*ln|x-p|+S(x)`。只有证明 R 在端点解析、S 有限，才分类：R(p)=0 时利用 `h*ln|h|→0`；R(p) 非零时依据其符号返回无穷。不能先把两项算成无穷后相减，也不能只看对数而忽略 S 的另一处极点。例如 `ln(x)+1/x` 必须交回通用极限。

限制为有理端点、至多四个仿射对数和固定节点/幂次预算。非线性对数、未知参数符号、对数乘积、其他振荡项及未经证明的可去分母都不强行套用。40 项独立规则检查覆盖接受和拒绝条件；完整积分测试另用分部积分恒等式证明一族正负斜率、不同分母幂次和反向区间。

## 2. 根式积分：保留原定义域的有界换元

旧根式识别遍历嵌套根节点，再用求导判断是否线性；求导又会进入根式识别，形成深调用链。现在只枚举乘积的直接因子，按结构提取一次出现的根式，减少重复扫描和临时向量。系数中仍含该根节点时不假设独立。

对 `P(x)*(a*x+b)^(±1/2)`，用 u=a*x+b 作精确有界二项式平移，再以 Horner 形式构造原函数。次数上限 8 只需九个有理系数，避免通用代数扩域和根搜索；同时限制节点、系数位数和中间多项式规模。零平移的常数单项式直接用 1，避免把多项式系数送入数值 0^0；旧的 sqrt(x)*ln(x) 分部积分回归暴露了这一问题，现增加正负斜率的零截距检查。

对 `P/(c*sqrt(A)+d*sqrt(B))`，须先证明 A、B 仿射、实域内部非空、c 与 d 同号、两根不同时为零。然后仅在 `P/(c²A-d²B)` 确为有界多项式时使用共轭恒等式。被消去的是共轭因子引入的假零点，而非原分母的零点。例如 x/(sqrt(1+x)+sqrt(1-x)) 在 x=0 仍有效；换成根式之差后不能照搬此证明。

22 项规则检查含空域、单点域、同根零点、相反符号、不可整除、额外变量、复根及预算上界。完整积分另外独立求导验证不同次数、正负斜率、加权根和允许端点。没有把拒绝规则等同于“这道积分数学上不可求”。

## 3. 绝对值复合求导：检查整个函数的接点

单独 `abs(Q)` 不可导，不代表 `H(abs(Q))` 在同一点不可导。若 H 在 t≥0 解析且 H'(0)=0，`H(|Q|)-H(0)=O(Q²)`，多项式 Q 的所有零点均可导。若 H'(0)≠0，则 Q 的驻零点导数为零，简单零点仍是真角点。

新规则证明所有对数参数和分母在 t≥0 严格为正，然后使用上述差商结论，避免枚举高次多项式根。它只接受一个绝对值复合及有限的解析函数语法。非负多项式系数加正的常数项是充分条件，不是完整的正性判定算法；证明失败不会被当作不存在导数。

斜率直接由各项导数在零点的值确定，无需先对整个导数通分。多个独立分母的和若无条件通分，会增加高次分子和中间数据拷贝，却不给接点证明增加信息。资源变式同时要求短表示、精确导数和真实的零点不可导分支。

## 4. 化简不能改变零点和禁取值

删除了旧的 `sign(u)→abs(u)/u` 替换：sign(0)=0，而右式在零点无定义。该替换会使原本平坦的指数/有理绝对值复合重新产生 0/0。现在保留 sign 节点，继续化简周围代数。

三角根式比值还可能在共轭约分时丢掉原来的余弦分母。保护检查针对真正含三角函数的分母，避免连除以常数的普通对数化简也被阻止。周期验证覆盖余弦的全部零点类别，并实际代入排除点；不以几处浮点数相等代替定义域证明。

这仍是有界的定义域保护，不是覆盖所有表达式的域传播系统。有些分母事实上严格正，但尚无相应证明，化简会保留较长原式。明确写出条件的短式需要另一套可靠的条件表示和证明，不能仅靠字符串整理。

## 5. 展开预算：先估算，再决定是否展开

10 个二进制幂因子的乘积只有短输入，却能展开成 1024 个单项式。该题的紧凑乘积本身就是精确答案，不必生成完整系数向量。

化简的项数计数采用饱和值：多变量继续在超过 64 项时保留原式；新增单变量超过 256 项的保留条件。计数器饱和值调整为 257 是为了区分两个阈值，不是扩大实际展开预算。小多项式的正常约简继续单独回归。对紧凑表达式保留，不表示把尚未求出的积分也算作通过。

## 6. 验证方法及证据边界

- 旧的测量脚本允许记录失败后正常退出，现为 checkpoint 回归启用 require-solved；采样通过仍单独标注，不升级为精确证明。
- 保存出题后、修改前的原始结果，修复结果另存；同一题的四种模式不算四道独立题。
- 对完整定义域给出代数或解析证明；实际输出重新求导验证，零点、端点、分段条件另在程序中代入。
- 独立检查程序只在已排除零点的开区间使用 sign(u)=u/abs(u)；接点仍检查实际返回值，不能用验证器自己约分掩盖程序的孔点。
- 对原函数的单侧端点导数，与普通双侧导数明确区分。`asin(sqrt(x))²` 在零点有右导数 1，不能据此宣称其原定义域上存在双侧导数。
- 探针使用计算器实际链接的 `zusual.cc` 基础函数实现，以及仓库积分、求导、FXCG 化简和条件处理。其他依赖仍有主机库；SH4 链接和容量另验。
- 外部超时、输出上限和 64 KiB 栈是测试约束。编译器单函数栈帧不能相加冒充运行峰值，主机 RSS 也不能冒充计算器堆占用。

## 7. 下一步仍需关注的缺口

通用极限与代数扩域仍有深递归路径；对任意超越复合的接点判定、复杂参数条件、所有继承定义域和全局最短表示，当前没有完备算法。新增短路规则只缩短已证明的一类路径，不能保证所有剩余路径都不会触及栈或内存限制。

资源已接近 CG50 的实际链接容量，应优先删除重复工作和不必要展开，评估每项新规则的代码成本。不会以扩大堆/栈预算、数值近似替代精确答案或隐去失败题来宣称覆盖完成。下一批仍由全新的出题代理提供，主代理独立验收；只要首次有失败，继续修复循环，尚不派发最终性能审查代理。

当前验证数据、容量和测量结果见 [第十七轮记录](POLAR-STABILITY.md#第十七轮对数端点根式换元与绝对值接点的结构审查)。本轮函数族共 99 个输入、396 种运行模式；另有 62 项规则接受/拒绝检查。

## PC18：根式分母、符号矩阵与测试环境

本轮首先在未修改的 `56b5d37` 上运行六道独立新题，四道完整通过。两个失败族分别是：根式导数经外层 `simplify` 后在内部正常点出现新孔洞；固定 3×3 符号行列式进入多变量有理消元，在主机 64 KiB 计算栈上崩溃。原始输出和首次验收保存在 `polar-cycle18-first-*.json`，后续通过不能改写首次失败记录。

### 根式：恒等式成立不代表定义域相同

`diff(ln(1+sqrt(1-x^2))-sqrt(1-x^2),x)` 在 `(-1,1)` 等于 `x/(1+sqrt(1-x^2))`，特别是在零点为零。将它改写成 `(1-sqrt(1-x^2))/x` 却会引入 `0/0`。因此本次处理的是有理化的前置条件：对规模受限的表达式，只要逆元或除法的分母包含加法及平方根，就保留该表达式，不再无条件使用共轭分母。检查覆盖乘积、乘幂、负系数、两根式和常数根式，而非只识别这一条导数。

这种保护是保守策略，可能放弃一些合法化简；不能称为已经输出最短教科书形式。根式终点处的单侧导数，也不能冒充普通双侧导数。本轮对数化简题仍保留携带原定义域的表达式，不能把这一结果宣称为已经规范化为零。

### 行列式：先确定代数规模，再选择无除法算法

实际计算器链接 `zvecteur.cc`。原崩溃回溯经过 `_det → mrref → rdiv → normal → simplify_gcdpart → gcd_modular`；单独编译实际 `_det` 入口也复现了同一路径。主机探针现在包含实际入口及新头文件，但通用消元依赖仍来自主机 Giac，不能说它模拟了整个 SH4 实现。

新路径限于 2–4 阶、最多 512 个输入节点的符号矩阵。先以有界语法遍历取得多项式分子及共同分母；不调用一般有理函数 GCD，也不把 `1/(N/D)` 翻转后忘掉内部孔洞。不同符号分母、非多项式、过高次数和超预算输入退回既有算法，数值矩阵继续使用原数值路径。此处“退回”不等于证明任意大输入都安全。

若 `B=A-I` 的所有 2×2 子式精确为零，则 `rank(B)≤1`，由行列式的多线性得到 `det(I+B)=1+trace(B)`。不要求 `B` 可逆，也不使用可能为零的符号主元。否则使用列子集递推，最多 16 个中间表达式，计算完整小矩阵行列式；乘积保留因式形式。计算出的分子超输出节点预算时保留原行列式。共同分母的零集通过显式条件保留，即使结果在允许区域恒等于 1 或 0，原矩阵的孔洞也不能消失。

初版扩展测试又找到八次小栈崩溃：短的 `(x+y)^4*(x-y)^4` 被旧展开估算当作大量单项式，导致本应可处理的小矩阵退回通用消元。修复使用复合乘幂底式作为形式多项式变量；每个底式仍先证明为有界多项式。形式多项式恒等为零，在代回实际底式后也必为零；底式之间未识别的关系最多使秩判定失败，随后完整无除法算法仍然有效。没有扩大原全局展开预算。

独立验证包含一般对角背景加秩一更新（包括一个或多个零对角元）、固定种子的满秩多项式矩阵及带孔洞的幂零更新。参考使用列多线性公式或 SymPy 的 Berkowitz 算法；同时比较整个分母零集，并在计算程序中实际代入被排除平面及允许点。另有拒绝条件测试，防止扩展匹配范围时误接收不适用输入。

### 主机小栈测试器的退出故障

将历史积分总表也放到 64 KiB 工作线程后，旧版和新版均出现一批 `SIGSEGV`。代表题的 GDB 回溯显示计算已返回 `ln(3)/4`、工作线程已结束，随后主线程在 `NTL::FFTMulTabsDeleterPolicy::deleter → FFTPrimeInfo 数组析构 → __cxa_finalize` 中崩溃。原失败报告另存为 `host-thread-exit-failures-polar18-2026a.json`，不把这种退出错误计作通过，也不归因为计算器 TLB。

公共积分探针改为主线程上的独立映射计算栈，两端各有不可访问保护页，以 `swapcontext` 切换；计算栈仍为实际指定的 64 KiB。局部析构在计算栈执行，返回后正常退出进程和清理主机库，不使用 `_exit` 跳过析构。专门测试要求故意溢出的程序确实收到 `SIGSEGV`，并验证正常路径的局部和全局析构都执行。极坐标显示探针仍使用原工作线程测试，报告应区别测试器，不能混称硬件仿真。

### 扩大历史小栈覆盖后继续修复

排除退出故障后，历史总表还有五道在实际计算过程中溢出：2018-Q8 的嵌套链式求导、2010-Q19 与 2023-Q18 的混合三角/指数有理函数，以及 Princeton-Imp10 和 2012-Q8 的三角积分。另有一道仅独立主机验证器在小栈下失败；验证器现在在普通栈验证已打印结果，目标计算仍受 64 KiB 限制，两者分别记录。

代码提取器过去还丢掉了函数前的 GCC `noinline,optimize("Os")` 标记，本轮予以保留，同时正确跳过前置声明。仅恢复标记未消除这五道失败，因此又重构了实际 `yderive.cc`：将加法、乘法、乘幂、倒数的原有分支逐段移出大型分派函数；特殊函数和高阶导数另用一个函数。常见标量三角/指数函数的链式求导在保留绝对值复合规则和依赖检查后走短路径。没有针对题目替换导数公式，也没有放宽原分支检查。

三角积分的回溯还揭示，`lnabs` 为构造 `ln|u|` 调用了全局 `abs(u)`，进而进入 `sturmsign → find_range → fminmax → limit`。对于符号参数，本轮直接构造原本就需要的 `ln(abs(u))`；数值参数和复数模式保留各自既有处理。省去的是不必要的全局符号判定，绝对值并未移除。

`logarithmic_span.h` 增加有界的对数导数线性组合识别：从原分母取得最多三个因子 `D_j`，在共同分母下，精确匹配 `c D + sum(b_j D_j' product(D_k,k!=j))` 与分子。系数系统最多四列、64 行，仅做有理数运算并逐步检查位数预算。候选由分母结构给出，系数由完整形式多项式恒等式解出，不使用随机采样或猜测小整数。允许的构造由有理多项式及整域上的实 `sin/cos/exp` 复合组成；未知参数、内部对数/根式/正切极点及不在候选空间内的表达式明确拒绝。把超越函数当成独立形式变量是充分性证明，可能漏解，但不会把不成立的恒等式证明为真。

多个对数可能在共同零点相消，因此结果保留原分母的条件。只有一个非零系数的对数时，其自身已经使分母零点不具有有限值；此时保留自然的对数端点，让极限引擎继续判定普通广义积分。曾发现统一套条件会让 `integrate(1/(exp(x)-1),x,0,1)` 停留未求值，已按上述数学条件修正，不能把这一回退记作通过。

资源复核还进一步移出了点对象和单位圆 Li2 的特殊求导分支，使 SH4 的公共分派帧从原 256 字节降到 72 字节。不能只报告这一单帧降幅：保守相加后的分派＋加法／乘法／乘幂／倒数帧分别为 180／236／244／152 字节，均低于原分派帧；特殊函数路径是 72＋220＝292 字节，高于原 256 字节。这些数字只比较涉及重构的编译器帧，尚未包括递归 `derive`、算术子程序与库函数，不能称为实机总栈峰值。稀有路径的增加是明确保留的代价，其余旧题和分支测试必须继续验收。

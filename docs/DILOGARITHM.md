# Li2 与积分扩展

源码 checkpoint：`checkpoint/dilogarithm-2026a`。可以输入 `Li2(x)`、`evalf(Li2(2))` 和 `diff(Li2(x),x)`；Li2 是注册的内置函数，具有实际数值实现和导数元数据。

## 符号规则

由 `d Li2(u) = -ln(1-u) du/u`，直接识别单项式、仿射和指数换元。额外除以 `1-u` 时，利用 `1/(u(1-u))=1/u+1/(1-u)`，追加 `-ln(1-u)^2/2`。这避免通用有理展开和反复构造中间表达式。

例如：

- `integrate(ln(1-x)/x,x)` → `-Li2(x)`。
- `integrate(ln(1-x^2)/x,x)` → `-Li2(x^2)/2`。
- `integrate(ln(1-exp(-x)),x)` → `Li2(exp(-x))`。
- `integrate(ln(1-x)/x,x,0,1)` → `-pi^2/6`。

匹配限制为96个表达式节点、最多4个因子和受限有理常数；幂次绝对值不超过32、分母不超过16。超限或结构不匹配交给原有方法。定积分只直接处理已证明换元区间不穿过Li2实支割的有限端点；附加对数极点不能当作可积端点。

`ln(1+d*x^q)*w*x^n` 在零点等价于 `d*w*x^(q+n)`。在规定的正实区间内，若 `q>0` 且 `q+n<=-1`，直接返回有符号无穷。该规则修复 `simplify(integrate(ln(1+x)/x^2,x,0,1))` 的主机64 KiB栈崩溃，并验证了不同幂次、负号和反向积分限。

## 数值算法与分支

采用复数double。小参数直接求级数，最多48项；较大参数先做倒数和反射变换，最多两次递归约化。在约化区域 `|log(1-z)|<=pi/3` 内使用固定12项偶阶Bernoulli展开。对数模长使用缩放，避免有限但极大的实虚部导致模长溢出。

采用主支解析延拓，支割为 `[1,+infinity)`。实数轴支割上的字面输入取 `Log(negative)=+i*pi`，因此 `Li2(2)=pi^2/4-i*pi*ln(2)`；从上半平面逼近则虚部为正。两侧极限分别核验，没有把实轴约定与上侧极限混为一谈。0、1、-1和1/2具有精确特殊值。

数值结果精度为double级别；即使传入高精度数，也不承诺任意精度Li2。通用导数打印为 `-ln(1-x)/x`，零点是可去奇点，直接代入此打印式得到 `undef`，使用 `limit(...,x=0)` 得1；导数回调在实参0时也返回1。
